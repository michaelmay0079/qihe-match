# 契合码 · Qihe Code

> 把相亲资料变成一个可以贴出去的「码」。双向达标才交换联系方式，全程不经过任何服务器。

🔗 **在线体验**：[README 发布后替换为你的 Pages 地址]

---

## 这是什么

相亲时最尴尬的两件事：**资料一贴出去，年龄收入就被所有人看光**；**留了联系方式，又被不合适的人反复打扰**。

契合码想解决的就是这两件事：

- 你的资料**加密成一段码**，对方看不到里面写了什么；
- 对方**先证明自己符合你的要求**，才可能拿到你的联系方式；
- 全程**没有服务器、没有账号、不需要注册**，一个 HTML 文件在浏览器里跑完。

---

## 四种用法

分「我发布」和「我匹配」两个方向，各有「直接给码」和「经第三方地址中转」两种方式，合起来四条路。**你只需要走自己那一条。**

| | 场景 | 前提 |
|---|---|---|
| **①** | 我发布 → 对方匹配 → 对方当场拿到我的联系方式 | 我选「开放模式」 |
| **②** | 我拿到对方的图 → 我匹配 → 我当场拿到对方联系方式 | 对方选「开放模式」 |
| **③** | 我发布 → 对方匹配 → 对方把 S2 贴到贴吧 → 我解出 S3 贴回 → 对方拿到我 | 我选「双向解锁」 |
| **④** | 我拿到对方的图 → 我匹配 → 我把 S2 贴出去 → 对方解出 S3 贴回 → 我拿到对方 | 对方选「双向解锁」 |

①② 是**即时**的，当场出结果。③④ 是**异步**的，中间可能隔几天，靠贴吧/评论区传话——这也是为什么软件会**强制你导出密钥备份**：私钥一丢，对方贴出的码就永远解不开了。

**可以同时回应很多人。** 你回应 5 个人会生成 5 份不同的 S2，各自只能被对应的人解开；对方贴回的 S3 里带引用号，软件会告诉你这是谁回的。

## 为什么不是「又一个交友 App」

| 常见做法 | 契合码 |
|---|---|
| 资料公开，所有人可见 | 逐字段选择**公开 / 加密 / 隐藏**，隐藏项连字段名都不写入 |
| 平台存你的资料 | **没有平台**，码在你手里 |
| 付费解锁、会员等级 | 不收费、无会员、无广告 |
| 平台审核身份 | **不审核，也不假装审核**——全部为自述，页面明确写出这一点 |
| 留手机号 | 建议用邮箱/匿名留言板，**不要填手机号** |

## 现实校准：把「要求」的代价摆在明面上

填完要求后，软件会告诉你在你所在的城市、你要求的年龄段里，同时满足学历与收入门槛的人**大概有多少**，以及对**每 100 个同龄未婚异性**来说这个比例是多少。

数据全部来自公开统计：

- 第七次全国人口普查（分省人口结构、受教育程度）
- 《中国统计年鉴 2025》（2024 年分省结婚登记）
- CFPS 2023（分年龄收入中位数）
- 教育部《全国教育事业发展统计公报》（招生数 → 学历分布）
- 各地方统计局（人均可支配收入与消费支出）

**它会说实话**：如果要求超出当地现实，它会直接写「这属于本地前 0.3%，池子极小，且对方同样会筛人，你能触达的概率远低于这个人数占比」，而不是给你一个看起来可行的绝对人数。

## 隐私与安全

- **零服务器**：编码、加密、判定、解密全部在你的浏览器里完成（Web Crypto API），不上传、不落库、不留日志。
- **加密强度**：RSA-2048（密钥封装）+ AES-256-GCM（内容整块加密）。
- **不核验任何信息**：学历、房产、婚史、健康、收入全是自述。加密保护的是「谁能看到」，不是「内容是否真实」。
- **本产品没有客服**：任何以「契合码客服」名义要求转账、充值、解冻的，一律是诈骗。

末页内置了防诈骗指引（含诈骗罪的金额档与定罪核心）、相亲见面四关流程（公共场所 / 核实身份 / 家人报备 / 止损线）、以及一份「爱情宝典」。

## 怎么用

### 只想试试

打开在线地址，随便填一填，看「现实校准」那一屏就够了。所有计算在本地，不留痕迹。

### 真的想用

1. 下载本仓库的 `index.html`（右键另存，或 `Code → Download ZIP`）
2. 双击用浏览器打开 —— `file://` 也能跑，**完全离线可用**
3. 填表 → 生成 → 导出载体图 → 发出去

### 载体图是什么

序列本身约 1,300 字符，直接塞照片会让体积涨到几万字符（微信、微博都发不出去）。所以做成载体：

- **你的照片**：序列以微缩文字印在图片底部，同时以无损数据块嵌在 PNG 里 —— 图片能正常看脸，对方用本软件即可读出序列。
- **默认风景图**：不传照片时自动生成，配色由序列哈希决定，同一序列必得同一图案。

> ⚠️ **必须用「发送文件」，不要用「发送图片」** —— 图片通道会重新压缩，嵌在文件里的数据会被抹掉。

## 技术说明

- **单文件**：`index.html`，无构建、无依赖、无 CDN。
- **隐私优先**：不引入任何第三方脚本、统计、字体。
- **密钥存储**：私钥存在浏览器的 localStorage，可在「导出密钥备份」里导出为 JSON。**公用电脑请勿生成。**

## 已知局限（如实写出来）

- **打印场景尚不支持**：纸面无法携带 PNG 元数据，微缩水印印出来约 0.44mm，拍照必然糊。打印需改用二维码（功能待实装）。
- **省级精确度有限**：省级系数只作用于收入通过率，未调整人口基数。
- **不做平台级安全**：不提供实名认证、人脸核验、内容审核——这些都需要服务端。
- **信息不核验**：所有字段为自述。
